# Crystal-Design-3D-Website-Powerful-Modern-Web-Design-Template
قالب حرفه‌ای طراحی وب‌سایت با انیمیشن‌های سه‌بعدی، Three.js و GSAP – مناسب برندها، استودیوهای خلاق و پروژه‌های مدرن  A powerful modern 3D website template built with Three.js, GSAP &amp; WebGL — perfect for agencies, brands and creative studios


Crystal Design یک پروژه متن‌باز در زمینه طراحی و توسعه وب‌سایت‌های مدرن و قدرتمند است.
این قالب با تمرکز بر جلوه‌های بصری حرفه‌ای، انیمیشن‌های سه‌بعدی و تجربه کاربری سطح بالا ساخته شده
و می‌تواند پایه‌ای قدرتمند برای وب‌سایت‌های شرکتی، استودیوهای خلاق و برندهای دیجیتال باشد.
